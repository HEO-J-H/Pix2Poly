# Pix2Poly 사용 안내

## 도움말 검색 사용법
- 화면 오른쪽 위 **❓ 도움말**을 누르고 궁금한 것을 입력합니다. 예: "사진 몇 장 찍어야 해?", "GLB 와 OBJ 차이", "배경 지우기".
- 답은 이 저장소의 README·설계 문서에서 가장 관련 있는 부분을 찾아 보여 줍니다 (AI 가 새로 지어내지 않음 — 문서에 없는 건 나오지 않습니다).
- 인터넷 연결 없이도 동작하고, 입력한 질문은 어디에도 전송되지 않습니다.

## 사진 1장 → 부조 3D
- 정면에서 찍은 사진 1장을 넣으면 밝기를 높이로 바꾼 부조(浮彫) 메시와 PBR 텍스처 5종(Base Color·Normal·Roughness·Height·AO)을 만듭니다.
- 사진은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.
- 높이 세기·해상도 슬라이더로 결과를 조절하고, GLB 또는 OBJ 로 내려받습니다.

## 여러 각도 사진 → 하나의 3D
- 같은 물체를 돌아가며 찍은 사진 2~4장을 넣으면 공개 AI 데모(TRELLIS, MIT)가 색까지 입힌 GLB 를 만듭니다.
- 이 기능만 사진이 Hugging Face 서버로 전송되며, 전송 전에 동의를 묻습니다. 무료 공유 GPU 라 대기·하루 사용량 제한이 있습니다.
- 내 PC 에서만 처리하려면 로컬 실행 버전에서 사진 5장 이상(권장 15~40장, 옆 사진과 60% 이상 겹치게)으로 사진측량(COLMAP)을 씁니다.

## 잘 찍는 법
- 반짝이·투명·무늬 없는 단색 표면은 복원이 어렵습니다 (무광 처리·무늬 테이프가 도움).
- 물체 둘레를 일정한 간격으로 돌며, 높이를 바꿔 한 바퀴 더 찍으면 위·아래가 잘 나옵니다.
- 배경이 복잡하면 '배경 지우기'를 켭니다 (rembg, 이 PC 에서 처리).

## 결과 파일
- GLB: 텍스처까지 한 파일 — Blender·Unity·Unreal·웹(three.js)에서 바로 열립니다.
- OBJ: 메시 + 재질(MTL) + 텍스처 이미지 — 오래된 프로그램과도 잘 맞습니다.

## 제한 사항
- 사진 1장 방식은 '앞에서 본 높이'만 만들므로 뒷면이 없습니다 (부조·간판·타일·벽면 장식에 적합).
- 여러 각도 AI 방식은 공유 GPU 상황에 따라 실패하거나 오래 걸릴 수 있습니다 — 실패하면 이유를 보여 줍니다.
