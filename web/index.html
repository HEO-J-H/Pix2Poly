💻 내 PC에서 만들기

권장 · 사진이 밖으로 나가지 않음 · 사용량 제한 없음

공식 오픈소스 COLMAP(사진측량, BSD 라이선스)으로 이 PC 안에서만 계산합니다.

  1. Pix2Poly 내려받기 (ZIP) → 압축 풀기 (Windows · Python 3.10 이상)
  2. scripts\install-colmap.bat 더블클릭 — 공식 COLMAP 자동 설치 (NVIDIA GPU 가 있으면 정밀판)
  3. run.bat 더블클릭 → 열린 화면의 여러 장에 사진 넣기
잘 나오게 찍는 법
  1. 물체 주위를 한 바퀴 돌며 15~40장 (최소 5장), 옆 사진과 60% 이상 겹치게
  2. 물체는 그대로 두고 사람이 돌기 · 흔들린 사진은 빼기
  3. 반짝이·투명·무늬 없는 단색 표면은 복원이 어렵습니다 (무광 처리·무늬 테이프가 도움)
  4. NVIDIA GPU 가 없으면 대략적인 형태만 — 복원이 안 되면 이유를 알려 줍니다
🌐 설치 없이 브라우저에서 (공개 AI 데모 · 선택)

2~4장으로 AI(TRELLIS, MIT)가 형태를 추정합니다. 사진이 Hugging Face 서버로 전송되고, 무료 공유 GPU 라 대기·하루 사용량 제한이 있어요.
